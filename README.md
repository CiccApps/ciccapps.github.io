# CiccApps

Una colección de apps hechas a medida: **Bitácora**, **La Taquilla**, **Banda Sonora** e **Interés compuesto**.

Web: https://ciccapps.github.io

- Cada app vive en su carpeta y se instala por separado en la pantalla de inicio.
- Los datos personales se guardan en Supabase (servidor en París) con seguridad por usuario: cada cuenta solo ve lo suyo.
- `.github/workflows/latido.yml` mantiene activa la base de datos del plan gratuito.
